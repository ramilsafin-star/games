# Наши игры

Детские браузерные игры на одной странице: https://ramilsafin-star.github.io/games/

- **Бибика** — гонки на 37 машинах по семи трассам.
- **Пушистый залп** — 18 уровней: стреляй пушистиками из рогатки, порталы, вихри, батуты и босс Гигабот.
- **Домик на дереве** — построй, укрась и обставь свой домик на большом дереве.
